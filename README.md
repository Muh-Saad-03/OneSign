# OneSign

OneSign helps to simplify the booking, cost, and paperwork in funeral planning in one location. Families only input in the details once, select a cemetery and time slot, view transparent costs with payment plans, and complete the legal forms with a single signature. The system generates a verified paperwork pack that reduces stress, avoids errors, and ensures a dignified process. Also includes chatbox AI to help users/customers.

Tools & Technologies:
React, CSS, HTML, Firebase Hosting(maybe), GitHub, Mapbox/Leaflet, pdfmake, Signature Pad, and Visual Studio Code.


Instructions:
1: Download all the files.
2: Open the files in VS CODE.
3: In order to run the files make sure you're on your home internet and not the school (or the server will not run/get blocked).
4: Open two terminals:
        input commands in Terminal one: cd packages/server
                                        bun run dev
        input commands in Terminal two: cd packages/client
                                        bun run dev
5: Hold down command and click the link which is provided in the terminal or click this: 
                                                                                        http://localhost:3000
