# OneSign 🕊️

**OneSign** helps simplify **booking, cost, and paperwork** in funeral planning in one location. Families only input details once, select a cemetery and time slot, view transparent costs with payment plans, and complete legal forms with a single signature. The system generates a verified paperwork pack that reduces stress, avoids errors, and ensures a dignified process.  
Also includes a **chatbox AI** to help users/customers.

## ▶️ Run Instructions ▶️

### 1) Download & open
1. Download all the files
2. Open the folder in **VS Code**
3. Use **home internet** (school network may block the server)

### 2) Start the server (Terminal 1)
```bash
cd packages/server
bun run dev
```
```bash
cd packages/client
bun run dev
```

### Lastly: Hold down command and click the link which is provided in the terminal or copy and paste this: 
```bash
http://localhost:3000 
http://localhost:5000
```
